# SAPUN HOME

Сайт хоумстейджера Анастасии Сапун на HTML, CSS и JavaScript. Без сборщика, зависимостей и внешних запросов при просмотре.

## Просмотр

```sh
python3 start.py
```

Откройте http://127.0.0.1:4173/. Также поддерживается открытие `index.html` напрямую: для `file://` кадры загружаются через `Image`.

## Дизайн и структура

Дизайн обновлён по материалам `Downloads/`: тёплый светлый фон, оливковые акценты, заголовки с засечками, тонкие линии и разомкнутые рамки. Контурные ссылки и кнопки получают заливку при наведении и клавиатурном фокусе. Стрелки — локальные Bootstrap Icons.

- Hero: слева текст, справа анимация квартиры. На телефоне блоки расположены друг под другом.
- Знакомство: фотография и текст из предоставленных материалов об Анастасии.
- Услуги: онлайн-проект и комплектация под ключ.
- Детали: интерьерные иллюстрации, не портфолио выполненных проектов.
- Этапы работы: от консультации до финального стейджинга.
- Контактный блок и модальное окно заявки. После заполнения формы Telegram открывается с готовым сообщением; пользователь сам подтверждает отправку.
- Прямые ссылки на Telegram и Instagram в подвале.

Секция «Те же метры» и её интерактивный ползунок удалены полностью.

## Анимация

123 JPEG-кадра из предоставленного видео. Прокрутка управляет canvas в обе стороны. При `prefers-reduced-motion` отображается финальный кадр, длинная закреплённая прокрутка отключается. На телефоне кеш ограничен 14 кадрами, на компьютере — 22; одновременно загружаются максимум четыре кадра.

Для замены видео используйте `scripts/extract-frames.swift`, обновите `frameCount` в `app.js` по `assets/frames/manifest.json`.

## Основные файлы

- `index.html` — разметка и контент.
- `styles.css` — визуальная система, адаптивность и состояния ссылок.
- `app.js` — покадровая анимация и логика модального окна заявки.
- `assets/logo.svg` — оригинальный SVG, предоставленный пользователем; используется также как favicon.
- `assets/anastasia-sapun.jpg` — копия пользовательской фотографии из `Downloads/обо мне.jpg`.
- `assets/frames/` — кадры предоставленного видео; исходный водяной знак сохранён.
- `assets/detail-*.jpg` — интерьерные иллюстрации из предыдущей версии.
- `assets/arrow-*.svg` — Bootstrap Icons, лицензия MIT рядом.
- `scripts/check-browser.mjs` — общая адаптивная проверка через Chrome DevTools Protocol, Node 22+; Chrome на порту 9224, сайт на 4173.
- `scripts/check-modal.mjs` — проверка модального окна, Telegram-черновика и отсутствия наложения прогресс-линии.
- `previews/` — скриншоты и результаты проверки. Актуальные свидетельства перечислены в `design-qa.md`.

Для размещения нужны `index.html`, `styles.css`, `app.js`, SVG-логотип, фотография, иконки, три `detail-*.jpg` и папка кадров. Серверная часть не требуется. Telegram/Instagram сохранены из предыдущей версии; внешние аккаунты не верифицировались.
